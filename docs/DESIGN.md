# DOMINO Design System

Direction: Architectural Modern Luxury.

- Continuous dark visual language.
- Product photography is the primary visual accent.
- UI/body font foundation: Inter.
- Avoid decorative gold, excessive icons, SaaS-style rounded cards and gratuitous animation.
- Mobile is a first-class experience, not a compressed desktop layout.
- Use safe-area insets and dynamic viewport units on mobile.

## Core palette
- Background: #050505
- Surface 01: #090909
- Surface 02: #0D0D0D
- Surface 03: #121212
- Text: #F4F4F1
- Secondary: #A6A6A2
- Muted: #71716D
